# Sway Config
My personal configuration for Sway.

## ⌨️ Keybinds
* `SUPER + g` — Terminal
* `SUPER + c` — Kill window
* `SUPER + l` — Swaylock
* `SUPER + Shift + e` — Exit session
* `SUPER + Shift + s` — Screenshot (saved on clipboard)
* `SUPER + LMB` — Floating window

*Note: In `sway/config` also keys for Fn+F functions, specific to ThinkPad; if you don't need them, remove them.*
